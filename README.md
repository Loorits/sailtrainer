# Trim — website

A static site. No server, no build step required to deploy: the files here are
ready to upload as they are.

```
index.html        landing page (marketing, pricing, FAQ)
app.html          the trainer
app.js            bundled trainer (built from src/)
shot-*.svg        screenshots — generated by the trainer itself, not mock-ups
src/main.jsx      site shell: tier flag, top bar, checkout hook
src/trainer.jsx   the trainer source
```

## Run it locally

```bash
cd trim-site
python3 -m http.server 8080
# open http://localhost:8080
```

Opening `index.html` directly from the filesystem will not work — ES modules
need to be served over HTTP.

## Deploy

Any static host. Drag the folder onto **Netlify Drop**, or:

```bash
npx vercel deploy --prod      # Vercel
npx netlify deploy --prod     # Netlify
# Cloudflare Pages / GitHub Pages / S3 — same idea, upload the folder
```

Point your domain at it and you're done.

## Rebuild after editing the trainer

Edit `src/trainer.jsx`, then:

```bash
npx esbuild src/main.jsx --bundle --format=esm --jsx=transform \
  --external:react --external:react-dom/client --outfile=app.js --minify
```

React is loaded from a CDN via the import map in `app.html`. To remove that
dependency, drop `--external:*` and React will be bundled into `app.js`
(about 130 kB larger, but then the site has no third-party requests at all).

## Launch period — everything free until 17 November 2026

`FREE_UNTIL` at the top of `src/main.jsx` unlocks every Pro feature for every
visitor until that date. The whole gate is still in place underneath; the date
just short-circuits it.

To start charging: set `FREE_UNTIL` to a past date (or `null`), fill in the
checkout URLs in `CONFIG`, rebuild `app.js`, and read "Wiring up real
subscriptions" below first — the gate is cosmetic until you do that work.

To extend the free run: move the date and rebuild. One line, one commit.

The landing page says 17 November in six places, and the FAQ promises that
anyone using Trim during the free period keeps Pro. If you change the date,
change those too — and keep that promise; it costs nothing and it is the
reason early users will talk about it.

## Tiers

| | Easy Trim (free) | Pro |
|---|---|---|
| Boats | 40 ft cruiser-racer | all five, incl. two catamarans |
| Views | cockpit, plan | + 3D, cutaway sections |
| Controls | sheets, traveller, vang, outhaul, car | + backstay, runners, cunningham, halyards, furling, pole |
| Conditions | steady wind, flat water | gusts, shifts, sea state, current |
| Extras | target speed, coach | polar diagram, ideal-trim marks |

The split lives in three constants at the top of the `App` component in
`src/trainer.jsx` — `FREE_BOAT`, `FREE_VIEWS`, `FREE_CTRL`. Move a feature
between tiers by editing those, then rebuild.

## Wiring up real subscriptions

**Read this before charging anyone.** Right now the Pro flag is
`localStorage.getItem("trim.tier")`. It gates the *interface*, not the code —
the physics for all five boats is in `app.js` and anyone who opens the console
can set the flag. That is a deliberate trade-off for launching quickly, and it
is fine while you are finding out whether people want this. It is not fine once
real money is involved.

**Fastest honest option — a hosted membership layer.** Outseta, Memberstack or
Lemon Squeezy will give you accounts, checkout, VAT/MOSS handling and a
JavaScript check you can call in place of `readTier()`. For an EU one-person
business the VAT handling alone is worth it. This needs no backend from you.

**If you want to own it — Stripe plus a small function:**

1. Create a product and a Payment Link in Stripe. Put the URL in
   `CONFIG.checkoutUrl` in `src/main.jsx`, and the customer portal URL in
   `CONFIG.portalUrl`.
2. Set the Payment Link's success URL to `https://yourdomain/app.html?checkout=success`.
3. Add a serverless function (Vercel/Netlify/Cloudflare, ~30 lines) that:
   - receives the Stripe `checkout.session.completed` webhook,
   - stores the customer's email and subscription status,
   - exposes `GET /api/me` returning `{ pro: true|false }` for the logged-in session.
4. In `src/main.jsx`, replace the `readTier()` call in `useState` with a fetch of
   `/api/me`. The `useEffect` already has the line commented in place.
5. Only then, split the bundle: move the Pro-only physics and views behind a
   dynamic `import()` that the server serves only to entitled sessions. Until
   you do this, Pro is honour-system.

Whatever you choose, keep the free tier genuinely useful. It is the reason
anyone gets far enough to consider paying.

## Prices

The €6/month and €54/year on `index.html` are **placeholders**. Set your real
numbers in the three `.price` blocks in `index.html` and in your payment
provider — they are not read from anywhere, so they must match by hand.

Worth thinking about before you publish them:

- **VAT.** Selling digital services to EU consumers means VAT at the customer's
  rate. Below the EU-wide €10,000 cross-border threshold you can charge Estonian
  VAT; above it you need OSS registration or a merchant of record (Lemon
  Squeezy, Paddle) that handles it for you.
- **Sailing schools and clubs** are a better market than individual sailors for
  a tool like this. A crew or classroom licence at 10–15× the single price is
  usually easier to sell than a hundred individual subscriptions, and schools
  buy in the spring.
- **Seasonality.** Northern-hemisphere sailing interest collapses in November.
  An annual plan priced "for one season" survives that; a monthly plan will show
  heavy winter churn that has nothing to do with your product.
